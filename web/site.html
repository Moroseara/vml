A small language that runs anywhere you put it

vml compiles to compact bytecode and runs on a fast register VM. Errors are values, packages are folders, and vml build turns a project into one file you can hand to anyone. The playground below is the real compiler and VM, running in your browser as WebAssembly.

What vml is like

A statically typed language with a light syntax. Everything here compiles with the same vml you install.

Errors are part of the type

A function that can fail returns T ! E. Callers handle it with catch or pass it on with ?. Forgetting to handle an error does not compile.

func load(path: string): Config ! string {
    let text = fs.read(path)?
    return parse(text)?
}
let cfg = load("app.json") catch defaults()

Packages are folders

A module is a file or a folder, named by module and shared with pub. Files without a module line join the module that imports them.

## src/ui/mod.vml
module game.ui
import "./widgets"        ## internal file
pub func title(): string { return frame("menu") }

One file to ship

vml build writes a program you run directly. It carries the runtime with it, so the person you send it to does not need vml installed.

$ vml build
built dist/wc
$ ./dist/wc notes.txt
      42     318    2071 notes.txt

Embeds in C hosts

Register C functions, build types from C, run scripts with a fuel limit, and save precompiled .vmb images. The host decides which modules a script may import.

VML_Module *m = vml_module_new(L, "game");
vml_module_func(m, "spawn", "(name: string, hp: int): Entity", host_spawn);
vml_module_finish(m);
vml_load_file(L, "mod.vml");

Get started

vml builds from source with a C compiler. It is tested on macOS today; Linux support is next.

Build vml

git clone <repo> vml
cd vml
make -j8 && make test

Create a project

vml new hello
cd hello
vml run

Test and ship

vml test
vml build
./dist/hello
